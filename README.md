# 星空坐标学

给初学者的静态小站：从天球讲起，一直算到「给定时间和地点，一颗星在天空的方向和高度」。页面是普通 HTML，外观在 CSS，计算在一小段 JavaScript。代码里的中文注释讲给正在学网页的人：标签和样式规则是做什么的。

## 每个文件是什么

| 文件 | 作用 |
| --- | --- |
| `index.html` | 首页。站名、一段介绍、六课、虚拟观星和附录的目录。 |
| `lesson-01.html` | 第一课《天球是什么》。天顶、地平、天极、天赤道、黄道、春分点。 |
| `lesson-02.html` | 第二课《地平坐标系》。方位角从正北向东量，高度角从地平线向上量。 |
| `lesson-03.html` | 第三课《赤道坐标系》。赤经、赤纬，以及它们为什么能写进星表。 |
| `lesson-04.html` | 第四课《时间与恒星时》。儒略日、格林尼治恒星时、地方恒星时、时角。 |
| `lesson-05.html` | 第五课《坐标转换与升落计算》。高度、方位、中天、升落和拱极条件。 |
| `lesson-06.html` | 第六课《星星位置计算器》。填时间、地点和星名，页面列出每一步。 |
| `stargazing.html` | 虚拟观星。地面视角看东升西落，天球外观看整球怎么转。 |
| `stargazing-theme.css` | 虚拟观星的颜色、字体、字号和按钮样式。只放 CSS 变量。换外观改这一份。 |
| `stargazing.css` | 虚拟观星的布局。盒子怎么排，颜色用上面的变量。实用星座模拟也用这份布局。 |
| `constellations.html` | 实用星座模拟。全天 88 个星座的棍棒图、中文名、边界、地面透明和银河。 |
| `constellations-theme.css` | 实用星座模拟的颜色和字号。只放 `--sg-` 变量，和虚拟观星的主题分开。 |
| `constellations.css` | 实用星座模拟多出来的布局：搜索框、星座清单、滑块。 |
| `constellations-data.js` | 88 个星座的 J2000 星表、棍棒连线、边界和银河光带。数据写在文件里，`file://` 也能用。 |
| `stargaze-astro.js` | 虚拟观星的时间、恒星时、高度方位。调用 `calculator.js`，不算岁差。 |
| `stargaze-stars.js` | 虚拟观星用的 14 个北天星座 J2000 星表、棍棒连线和四季星群。 |
| `stargaze-render.js` | 把星图画到画布上。颜色从主题变量里读，不含按钮逻辑。 |
| `stargaze-controls.js` | 地点、时间、筛选、拖动、缩放和陀螺仪。 |
| `appendix-glossary.html` | 术语表。 |
| `appendix-stars.html` | 20 颗亮星的 J2000.0 赤经、赤纬。 |
| `appendix-advanced.html` | 岁差、大气折射，以及为什么行星不能用这张恒星表。 |
| `style.css` | 全站外观。颜色、字体、目录、课文、表格和计算器都在这里。 |
| `diagram.js` | 第一课的子午面图。拖动纬度时重画北天极和天赤道。 |
| `horizon.js` | 第二课的方位罗盘和高度侧视图。 |
| `calculator.js` | 第六课的全部计算，也是第四、第五课例题用的同一套公式。 |
| `favicon.svg`、`favicon.ico` | 浏览器标签上的小星星。 |
| `mascot/` | 测试版吉祥物深葵夜。首页问候、右侧陪伴、每课的复习对话。怎么接到别的网站，见 `mascot/README.md`。 |

深葵夜是齐肩白发、紫色眼睛、白皙皮肤的可爱样子，说话是成熟的傲娇，叫读者「观星者」。虚拟观星和实用星座模拟不加载她，免得挡住画布和控件。首页每天只播一次全屏问候；选「让我静静」之后会一直避开，直到点「我想你了」。

页面、样式和脚本都用相对路径（例如 `href="lesson-02.html"`），没有写死网址。

## 在自己的电脑上打开

1. 保存整个文件夹。
2. 双击 `index.html`。
3. 用浏览器从目录进入每一课。

不需要安装 Node.js，也不需要构建。字体用电脑里已有的中文字体。想看讲解，在浏览器里打开「查看网页源代码」。

第六课的计算器、前两课的滑块和虚拟观星需要 JavaScript。关掉脚本时，课文和星表仍然能读，第一课的图停在北纬 40°。

虚拟观星的外观和计算是分开的。想换颜色、字体、字号或按钮样式，只改 `stargazing-theme.css` 里的 `--sg-` 变量；画布上的星、线和地平也读这些变量，所以不用改 JavaScript。星表、公式和画图分别在 `stargaze-stars.js`、`stargaze-astro.js`、`stargaze-render.js`，按钮和时间在 `stargaze-controls.js`。这些脚本是普通的 `<script>`，没有构建步骤，用 `file://` 直接打开也能跑。

虚拟观星和第六课用同一套儒略日、恒星时和高度方位，星位是 J2000.0，不算岁差。核对时把地点设成北京（北纬 40°（取整）、东经 116.4°、UTC+8），时间设成 2026-03-20 20:00，面板上「织女此刻」的高度应约 −10.00°，方位约 11.98°。地址后面也可以加 `?time=2026-03-20T20:00&lat=40&lon=116.4&tz=8`。只勾选猎户座、并取消四个四季星群时，画面上应只剩猎户座。

实用星座模拟用同一套公式，另外带上全天 88 个星座。同一时刻、同一地点，织女仍是高度约 −10.00°、方位约 11.98°；天狼约 31.98°、194.88°；北极星高度约 40.17°，接近纬度。棍棒图改编自 Stellarium 贡献者的 modern 星空文化，恒星位置改编自 David Nash 的 HYG 星表第 4 版。这两份数据以及摘录后的 `constellations-data.js` 都以 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 发布（来源：[Stellarium](https://github.com/Stellarium/stellarium)、[HYG](https://github.com/astronexus/HYG-Database)）。边界是国际天文学联合会 1930 年的边界并从 B1875 岁差到 J2000。银河是沿银道的示意光带。页面不画星云。

## 这套计算精确到哪里

恒星时和高度、方位按 Jean Meeus《天文算法》的公式。星表是 J2000.0，没有加岁差，升落是几何高度 0°，没有加大气折射。和今晚的精密星历比，零点几度的差别是预期中的。附录「进阶话题」说明了这三件事。

## 以后发布到 GitHub Pages

把这些文件原样放进仓库，保持 `index.html` 在最外层。在 Settings → Pages 里选择分支和根目录（`/ (root)`）。相对路径在 `https://用户名.github.io/仓库名/` 下仍然有效。
